<objective>
Stand up the binary cache FOUND-03 requires: Attic on a small AWS EC2 instance with S3 storage,
declared in this flake, with server-side garbage collection configured to a nonzero retention
period, and a scoped push token handed to CI.

Purpose: without this, FOUND-01's "builds from the cache without compiling" has nothing to build
from and FOUND-02's publish step has nowhere to publish to. The cache is a production service
from Phase 11 on, so it is declared, not clicked together.
Output: a reachable cache endpoint, `nix/attic/cache-host.nix`, and an `ATTIC_PUSH_TOKEN`
repository secret.
</objective>
